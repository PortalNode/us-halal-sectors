# وسيط الأسعار اللحظية (Cloudflare Worker)

صفحات GitHub لا تستطيع قراءة أسعار Nasdaq مباشرة (المصدر لا يسمح بذلك للمتصفح)، فهذا الوسيط الصغير يقرأها ويعيدها للمتصفح.
مجاني (حد Cloudflare المجاني: 100 ألف طلب يوميًا) وبلا مفتاح API.

## النشر (دقيقتان، من المتصفح)
1. سجّل مجانًا في <https://dash.cloudflare.com/sign-up>.
2. من القائمة: **Workers & Pages → Create → Create Worker** → سمّه `us-halal-live` → **Deploy**.
3. اضغط **Edit code**، احذف الكود الموجود، والصق محتوى `worker/live-worker.js` كاملًا، ثم **Deploy**.
4. انسخ رابط الـ Worker (يشبه `https://us-halal-live.<اسمك>.workers.dev`) وافتحه: يجب أن ترى `{"ok":true,...}`.
5. جرّب: `<الرابط>/quotes?symbols=AAPL,NVDA` ← أسعار لحظية بصيغة JSON.
6. ضع الرابط في `live-config.js`:
   ```js
   window.LIVE_CONFIG = { workerUrl: 'https://us-halal-live.<اسمك>.workers.dev' };
   ```
   ثم ارفع التعديل إلى GitHub.

بديل بالطرفية: `cd worker && npx wrangler deploy`.

للتجربة قبل التعديل: افتح أي صفحة بإضافة `?live=<الرابط>` (يُحفظ في المتصفح، و`?live=off` يلغيه).

## ماذا يعطي
- `/quotes?symbols=A,B,…` (حتى 100 رمز): آخر سعر وتغيره ونسبته وحجم اليوم وحالة السوق وإغلاق أمس. يجلبها من ناسداك 20 رمزًا في الطلب.
- `/session?symbol=AAPL`: افتتاح الجلسة العادية وأعلاها وأدناها وآخر سعر (لتحريك شمعة اليوم في الشارت).

## ملاحظات
- المصدر «Nasdaq Last Sale»: صفقات لحظية لكنها من منصات ناسداك فقط، فقد يختلف السعر قليلًا عن السعر المجمّع لكل المنصات.
- مؤشر S&P 500 غير متاح من ناسداك، فيُقدَّر من حركة صندوق SPY.
- المصدر ليس واجهة رسمية موثقة؛ قد يغيّر Nasdaq شكلها أو يمنع طلبات Cloudflare. عند الفشل تعود الصفحات تلقائيًا للأسعار المتأخرة (TradingView) وتُظهر ذلك في سطر الحالة.
- اختبار محلي: `node worker/dev-server.mjs` ثم `?live=http://localhost:8790`.
